# AGENTS.md - MonteCarlo Ledger Android App Module

Agent-neutral startup router for the Android `app` module. Root `ENGINEERING.md` and root `AGENTS.md` remain authoritative for safety, verification, deletion, scope, and truthfulness.

## Startup

1. Read `C:\Workspace\ENGINEERING.md`.
2. Read `C:\Workspace\AGENTS.md`.
3. Read `C:\Workspace\MonteCarlo-Ledger-app\PROJECT_CONTEXT.md`.
4. Read `PROJECT_CONTEXT.md` in this directory.

## Local Rules

- Parent `PROJECT_CONTEXT.md` is the canonical project context.
- This module contains Android implementation details only.
- Financial math, persistence, and rounding behavior are high-risk.

## Verification

Run Gradle commands from the parent project root.
